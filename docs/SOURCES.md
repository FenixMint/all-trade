# Oficjalne źródła Allegro REST API

Dokumentację MZ-Trading opracowano na podstawie publicznych materiałów Allegro Developer Portal, przegląd **2026-10-20**. Treści Allegro i zakresy API mogą się zmieniać, dlatego przed wdrożeniem integracji należy sprawdzić aktualną wersję każdego odpowiedniego dokumentu.

## Przepisy i rejestracja

1. [Regulamin Allegro REST API](https://developer.allegro.pl/rules) — wymagania dostępowe, OAuth, identyfikacja aplikacji, ochrona klucza, zasady korzystania i odpowiedzialność.
2. [Pierwsze kroki](https://developer.allegro.pl/tutorials/pierwsze-kroki-MRwYEoOq0im) — wymagania rejestracji aplikacji.
3. [Allegro Developer Apps](https://apps.developer.allegro.pl/) — zarządzanie rejestrowanymi aplikacjami i uprawnieniami.

## Uwierzytelnianie i ruch API

4. [Uwierzytelnianie i autoryzacja](https://developer.allegro.pl/tutorials/uwierzytelnianie-i-autoryzacja-zlq9e75GdIR) — Authorization Code, Device Flow, client_credentials, scopes, tokeny.
5. [Informacje podstawowe](https://developer.allegro.pl/tutorials/informacje-podstawowe-b21569boAI1) — nagłówki, limity i identyfikacja aplikacji.
6. [FAQ Allegro REST API](https://developer.allegro.pl/faq) — format `User-Agent`, obowiązki identyfikacji, limity, praca z tokenami.
7. [Walidator User-Agent](https://apps.developer.allegro.pl/user-agent) — oficjalne narzędzie weryfikujące identyfikator aplikacji.
8. [Komunikat Allegro dotyczący User-Agent](https://developer.allegro.pl/news/do-konca-czerwca-2026-zaimplementuj-wlasny-niestandardowy-identyfikator-user-agent-w-twojej-aplikacji-q0K2EbxgXCg).

## Zasoby i eksploatacja

9. [Zarządzanie ofertami](https://developer.allegro.pl/tutorials/jak-zarzadzac-ofertami-7GzB2L37ase) — lista i szczegóły ofert, zmiany statusu, PATCH i kontrola asynchronicznych operacji.
10. [Pełna dokumentacja zasobów API](https://developer.allegro.pl/documentation/) — aktualne definicje endpointów, nagłówków i wymagań autoryzacyjnych.

## Zasada interpretacji

Dokumentacja w tym repozytorium wyjaśnia *planowany i dozwolony* zakres działania MZ-Trading. Nie tworzy własnego wyjątku od zasad Allegro. Jeżeli przywołane materiały różnią się co do limitów, rejestracji klucza, retencji czy warunków dostępu, weryfikacja bieżącego regulaminu i bezpośrednich wymagań Allegro ma pierwszeństwo przed zapisami repozytorium.

To repozytorium nie jest oficjalnym kanałem Allegro.
